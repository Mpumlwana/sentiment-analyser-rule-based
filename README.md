## 🎯 What does it do?

This tool reads a product review and decides whether it is **positive**, **negative** or **neutral**.
It uses a **dictionary of scored words plus hand-written rules** (VADER, a small domain lexicon and tuned thresholds). 🚫🤖 **No machine-learning model is trained.**

> 💡 **Why rule-based?** Every decision can be explained. The tool shows exactly which words drove the result.

## 🚀 Quick Start

### ☁️ Option 1: Google Colab (no installation)

1. 🌐 Click the **Open In Colab** button at the top, or go to [colab.research.google.com](https://colab.research.google.com) and choose **File > Upload notebook**.
2. 📤 *(Optional)* Upload `amazon_reviews.csv` using the folder icon on the left. If you skip this, the notebook downloads the dataset automatically.
3. ▶️ Choose **Runtime > Run all**. The first cell installs the packages and NLTK data.

### 💻 Option 2: On your own computer

1. 🐍 Install Python 3.9 or newer.
2. 📥 In this folder run:
```bash
   pip install -r requirements.txt
```
3. 📓 Run `jupyter notebook`, open `sentiment_analyser.ipynb` and choose **Run > Run All Cells**. NLTK data downloads on first run and needs internet.

⚠️ `amazon_reviews.csv` must stay in the same folder as the notebook. Running the notebook recreates the cleaned CSVs, `train.csv`, `test.csv`, `misclassified_test_reviews.csv` and the `figures/` images. 🎲 The random seed is fixed, so results are repeatable.

## 🏆 Headline Results

Evaluated on **1,474 unseen test reviews**:

| 🥇 Tool | Macro-F1 |
|---|---|
| 🏅 **Our analyser** (VADER + domain lexicon + tuned thresholds) | **0.485** |
| 🥈 VADER, default settings | 0.428 |
| 🥉 TextBlob | 0.385 |

> 📌 **Why Macro-F1 and not accuracy?** 90.5% of the reviews are positive, so a tool that always says "positive" would score 90% accuracy and still be useless. Macro-F1 gives every class equal weight.

## ⚠️ Known Limitations

- 😏 Sarcasm fools a dictionary-based tool
- 🔀 Mixed reviews ("good, but...") are hard
- 😐 The neutral class is rare and difficult
- 📖 Words missing from the dictionary are invisible to it
