The tool classifies a product review as **positive**, **negative** or **neutral** using a dictionary and rules (VADER plus a small domain lexicon and tuned thresholds). No machine-learning model is trained.

## Contents

| Item | Description |
|---|---|
| `sentiment_analyser.ipynb` | The analyser: data checks, cleaning and tokenization, exploratory analysis, three versions of the analyser, evaluation, error analysis |

| `amazon_reviews_clean.csv`, `train.csv`, `test.csv` | Cleaned data and the 70/30 stratified split (regenerated by the notebook) |

## Setup: Google Colab (no installation)

1. Go to colab.research.google.com, choose **File > Upload notebook** and pick `sentiment_analyser.ipynb`.
2. Click the folder icon on the left and upload `amazon_reviews.csv`.
3. Choose **Runtime > Run all**. The first cell installs the packages and downloads the NLTK data.

## Setup: on your own computer

1. Install Python 3.9 or newer.
2. In this folder run: `pip install -r requirements.txt`
3. Run `jupyter notebook`, open `sentiment_analyser.ipynb` and choose **Run > Run All Cells**. NLTK data (stopwords, punkt) downloads on first run and needs internet.

`amazon_reviews.csv` must stay in the same folder as the notebook. Running the notebook recreates the cleaned CSVs, `train.csv`, `test.csv`, `misclassified_test_reviews.csv` and the `figures/` images. The random seed is fixed, so results are repeatable.

## Trying the analyser on your own text

Section 5.7 defines `analyse(text)`, which prints the label, the compound score and the dictionary words that drove the decision. Section 5.8 is a live demo: set `RUN_INTERACTIVE = True`, run the cell, type a review and press Enter (type `quit` to stop).

## Headline results (unseen test set, 1,474 reviews)

| Tool | Macro-F1 |
|---|---|
| Our analyser (VADER + domain lexicon + tuned thresholds) | 0.485 |
| VADER, default settings | 0.428 |
| TextBlob | 0.385 |

Accuracy is misleading because 90.5% of reviews are positive, so macro-F1 is the main metric. See the report (Part E) for the full analysis and limitations (neutral class, sarcasm, mixed reviews).
